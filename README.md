# Remediation Tracking & Gap Closure Dashboard (GRC Workflow Simulation)

**Portfolio Project** | Demonstrates practical findings management, remediation tracking, evidence-of-closure workflows, and status reporting that simulates a lightweight GRC platform.

## One-Sentence Elevator Pitch
A practical remediation tracker and status dashboard that demonstrates how to log findings, assign owners, track evidence of closure, and report progress—simulating a lightweight GRC platform workflow.

## Business / Security Outcome
Provides clear ownership, aging visibility, and audit-ready evidence of remediation so compliance and engineering teams can close gaps efficiently and demonstrate progress to auditors or leadership.

## Tech Stack
- Microsoft Excel or Google Sheets — findings register, status dashboard, and charts
- Markdown + GitHub — documentation and templates
- Snagit — annotated screenshots
- Optional: free Notion or Obsidian for linked evidence notes

Free alternative to ServiceNow IRM, Archer, or AuditBoard.

## Key Features / Deliverables
- [ ] Findings register with severity, control reference, owner, due date, and status
- [ ] Evidence-of-closure checklist and attachment index
- [ ] Status dashboard with aging, owner workload, and closure rate charts
- [ ] Sample status report narrative for leadership or auditors
- [ ] Simple workflow diagram

## How to Complete This Project (24–48 Hours)
1. Build the findings register in Excel/Sheets using the guidance.
2. Populate 10–15 realistic sample findings.
3. Create the dashboard views and charts.
4. Complete the evidence-of-closure checklist and one sample closed package.
5. Write a sample status report.
6. Add a simple workflow diagram and screenshots.
7. Update this README with visuals and final talking points.
